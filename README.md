# Whoplayer app
# WIP
## Author: Wholock

I am not satisfied with cloud music services and plex/jellyfin apps require phones to be connected to VPN, which is annoying to say the least
So I started to develop a music player that can download music from different services, host it on your server and stream it straight to the app

Changelog:
* Finished API
* Added functionality to the phone app
* Added dockerfile and dockercompose file
